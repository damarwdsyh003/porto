# Damar's Digital Space

Damar's Digital Space is a personal developer portfolio for Muhammad Damar Widyansyah. It presents his backend and web development experience through a polished, responsive interface with a lightweight low-poly 3D character and workspace.

The portfolio brings together:

- About, experience, skills, and contact sections
- Selected internship and personal projects
- Dedicated project detail pages with technology stacks, responsibilities, and screenshots
- A downloadable CV
- Responsive navigation for desktop and mobile layouts
- Interactive 3D visuals powered by React Three Fiber and Three.js

## Tech Stack

- React
- Vite
- React Router
- React Three Fiber
- Three.js
- Drei
- Lucide React
- CSS

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Project Structure

```text
src/       React components, application data, and styles
public/    Static models and CV assets
media/     Portfolio media and project screenshots
doc/       Portfolio planning and supporting documents
```
